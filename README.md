# Josh Xtracsys

**30+ years in IT operations. Human-led product direction. Practical software built with AI.**

I turn real operational problems into useful tools. I set the goal, constraints, priorities, and acceptance criteria. AI tools help with research, implementation, and review; I own the product decisions and check the evidence before release.

## What guides the work

- **Keep people in control.** Make permissions, network activity, and consequential actions visible.
- **Protect user data.** Prefer safe defaults, local ownership, portable formats, and recoverable cleanup.
- **Make results checkable.** Define acceptance criteria, preserve useful history, and state what the evidence does not prove.
- **Build for real work.** Solve an operator's problem before adding novelty.
